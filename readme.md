#  Bangalore Flat Price Analytics

This project explores the **Bangalore House Pricing dataset** to analyze flat/house prices across different locations and features (BHK, sqft, bathrooms, etc.).

##  Objectives
- Clean and preprocess raw housing data
- Perform **Exploratory Data Analysis (EDA)** to uncover patterns
- Use **SQL + Excel + Power BI (DAX)** for analytics and visualization
- Build dashboards to present insights
